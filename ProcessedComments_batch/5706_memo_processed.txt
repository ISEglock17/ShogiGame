**Cleaning Up Game Comments for Analysis**

Okay, so I'm looking at this dataset of Shogi game comments, and the goal is to clean them up. The user, who's likely another Shogi expert like myself, wants to focus the comments on the actual game analysis - the board states and the rationale behind each move. Right now, the comments are cluttered with all sorts of irrelevant stuff – metadata, player introductions, time stamps, you name it. That noise makes it hard to quickly get to the core insights.

So, my task is pretty straightforward: I need to methodically go through each comment and, based on a set of rules I'll be provided, identify and remove anything that isn't directly related to the strategic analysis of the moves. The aim is to transform these comments into concise, natural explanations of the game as it unfolds. That will make the data much more valuable for deeper analysis, and help me extract meaningful strategic insights.
