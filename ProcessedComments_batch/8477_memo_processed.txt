**Cleaning Up My Commentary for Analysis**

Okay, so I've been asked to clean up some commentary data from shogi games. Essentially, they want me to take a messy collection of comments and turn them into something much more useful for analysis. The goal is to focus specifically on the game itself, the key moves and the thinking behind them, not all the extraneous fluff.

This means I need to sift through the comments and surgically remove anything that isn't directly related to the actual board position or the reasoning behind a particular move. Things like introductions of the players, time elapsed, any overarching meta-commentary that doesn't affect the board state - that all needs to go. My task is to strip away all the noise and leave only the pure, distilled analysis of the game itself, rendered in natural, flowing language. I'll need to develop a set of clear rules to define what stays and what goes, ensuring the final output is clean and readily usable for further investigation.
