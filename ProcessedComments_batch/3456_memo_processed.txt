**Processing Shogi Commentary: Focusing on the Core Analysis**

Okay, so I've got this task of taking Shogi game commentary from a user and cleaning it up. The goal is pretty straightforward: strip out all the fluff that's irrelevant for serious game analysis. Think of it like a digital autopsy, getting down to the bare bones of the game.

Specifically, I need to get rid of things like metadata, introductions to the players, timing information, anything that doesn't directly relate to the board state or the moves being made. I want to leave behind only the pure, insightful commentary on the positions and the reasoning behind each move, presented in a way that feels natural and flowing.

The process is fairly structured. I need to have a set of clear rules – a kind of "delete this" list – that identifies the specific types of information that are candidates for removal. This is the first step.
