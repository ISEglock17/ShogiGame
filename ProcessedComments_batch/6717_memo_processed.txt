I want to strip away all the extraneous noise – the player intros, the time stamps, anything that's not directly related to the actual moves and board state analysis.  I need to get to the core of the discussion!

Essentially, I need to methodically go through each comment and apply a set of rules, a filter if you will. I'll identify and eliminate all that irrelevant fluff, leaving behind only the pure essence of the strategic insights and move explanations. This way, I'll have a data set that's much more amenable to my analytical work.
