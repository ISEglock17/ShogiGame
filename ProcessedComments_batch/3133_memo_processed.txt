**Cleaning Up My Commentary for Analysis**

Okay, so I've been asked to clean up some commentary data from shogi games. Essentially, they want me to refine the text included in the game records. The goal here is pretty clear: I need to strip out all the fluff. That means getting rid of anything that doesn't contribute to the actual analysis of the game itself. No more player introductions, time stamps, meta-commentary, or anything else that doesn't directly explain the board state or the moves being made. I'm focusing on preserving the *substance* of the commentary – the actual analysis of the game. I figure I'll start by making a concrete set of rules and then use that to determine what can go and what stays.
