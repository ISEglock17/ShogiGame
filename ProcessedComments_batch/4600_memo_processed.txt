My plan of attack is clear. First, I'll go through the comments and apply a set of pre-defined rules to delete any information that doesn't fit the bill. Then, I'll work on making sure the remaining comments read smoothly and naturally, like actual explanations. Finally, I'll package it all up into the exact format that was requested, ready for further analysis.
