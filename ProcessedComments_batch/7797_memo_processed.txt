**Cleaning Up My Commentary for Analysis**

Okay, so I've got this dataset of Shogi game records, and I need to clean up the commentary associated with each move. The goal here is pretty straightforward: I want to strip out all the fluff that's not relevant to actual on-the-board analysis. Think things like metadata about the game, introductions of the players, time spent on moves – all that noise needs to go. I just want the core explanations of the board position and the rationale behind each move, presented in a clear, flowing narrative.

Essentially, I need to methodically identify and remove the irrelevant parts of the commentary based on a set of rules. This is the first step in creating a cleaner, more focused dataset for deeper analysis.
