**My Approach to Comment Formatting for Shogi Data**

Okay, so I'm tasked with refining comments embedded in Shogi game data. The goal is clear: I need to strip away all the extraneous fluff – the metadata, player introductions, time stamps – and leave behind only the core, insightful commentary about the board state and the moves made. This is all about making the data digestible for serious Shogi analysis.

My process will be straightforward: First, I'll meticulously scan each comment against a defined set of rules. Any piece of information that falls under one of those rules gets the boot. Then, with the debris cleared, I'll take what's left and smooth it out, ensuring it reads like a coherent, natural sentence.

Finally, the output needs to adhere to a specific format. It'll start with the move number, followed by the polished comment. If I have to ditch the whole comment, the format stays: move number, then an empty line. In that case, I'll detail the reasons for the removal in the "削除理由:" section, citing the relevant rule number.
