**Cleaning Up the Commentary for Analysis**

Okay, so I've been asked to clean up some commentary data from shogi games. Essentially, they want me to take a messy collection of comments associated with moves in a game and turn it into something useful for analysis.  My goal is clear: I need to strip out all the noise.  This means getting rid of anything that isn't directly related to the game itself, the *tactics*, the *strategy*.  I'm talking about removing all the unnecessary stuff – the meta-commentary, player introductions, time stamps...all that fluff. What I need to be left with are well-formed sentences that simply describe the board state and the reasoning behind each move.
