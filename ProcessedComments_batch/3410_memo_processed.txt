The goal is pretty clear: get rid of the extraneous stuff. That means all the metadata, who's playing, how long it took them to think, all of that.  I want to be left with the meaty bits - the descriptions of the board state and the reasoning behind each move, presented in a way that *feels* like natural language, not just a list of technical terms.

So, I'm thinking, I'll have to build this process out in a couple of steps. First, I'll need a set of rules – almost like a parser – to identify and remove all that extraneous information.  Then, with the core comments, I'll need to use some kind of natural language processing to make sure they are written in clear and natural language.
